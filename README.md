# 🌿 NutriVia — Your Midlife Health & Nutrition Companion

NutriVia is a Flutter-based mobile application designed to support women through midlife health changes with nutrition guidance, wellness tracking, and accessible health-related information. It aims to bring essential wellness tools together in one convenient platform.

## ✨ Features

- 🏠 **Personalized Dashboard** — Access key health information and wellness activities.
- 🥗 **Nutrition Support** — Explore nutrition guidance and food-related information.
- 🩺 **Health & Symptom Tracking** — Record health check-ins and monitor symptoms.
- 💊 **Medication Tracking** — Keep track of medications and related experiences.
- 🤖 **AI Health Assistant** — Access AI-powered health information and assistance.
- 🧘 **Movement & Wellness** — Explore activities that support everyday well-being.
- ⏱️ **Fasting Support** — Access fasting-related information and guidance.
- 📋 **Medical History** — Organize relevant health information.
- 📄 **Doctor Visit Reports** — Generate PDF reports to help prepare for medical consultations.
- 👨‍👩‍👧 **Caregiver Support** — Support family members and caregivers with relevant features.
- 🌐 **Accessibility & Language Support** — Make information more accessible through supported voice and language features.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Programming Language:** Dart
- **State Management:** Riverpod
- **Navigation:** GoRouter
- **Charts:** FL Chart
- **Local Storage:** SharedPreferences
- **AI Integration:** Gemini API
- **Voice Features:** Text-to-Speech and Speech-to-Text
- **PDF Generation:** PDF and Printing packages

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK compatible with the project
- Android Studio or Visual Studio Code
- Android emulator or compatible device

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd NutriVia-main
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
